ONLINE TOY STORE - EXPERIMENT 6
JAVASCRIPT - TIMER FUNCTIONS AND ARRAYS

Aim:
To create an Online Toy Store webpage using JavaScript timer functions, Date object,
events, classes, objects and arrays to display a live clock, change page colour,
animate a delivery vehicle and display student details dynamically.

Files:
- index.html: Complete HTML, CSS and JavaScript program.
- README.txt: Instructions.

Concepts used from the uploaded Experiment 6:
1. Date object and setInterval() for live clock and date.
2. setInterval() to change background colour every 30 seconds.
3. onmouseover and onmouseout to change font size.
4. setTimeout() and clearTimeout() to move and stop the delivery vehicle.
5. Toy class and object to display a featured toy and price.
6. Array of student objects, for loop and if/else categorization.

How to run:
1. Extract the ZIP folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Click Move and Stop to test the delivery vehicle.
4. Move the cursor over the Toy Store Note to change its font size.
5. Wait 30 seconds to see the background colour change.

Student records are sample records. Replace them with your actual class details if needed.
